FOODIES RESTAURANT WEBSITE – COMPLETE DOCUMENTATION

====================================================
1. PROJECT OVERVIEW
====================================================

1.1 Purpose
This project is a single-page restaurant website for “Foodies”. It focuses on:
- Presenting the restaurant’s brand, ambience, and cuisine.
- Displaying menu items in a filterable, searchable way.
- Providing a smooth cart experience fully on the frontend.
- Guiding users to key actions like viewing the menu and booking a table.

The application is front-end only; there is no real backend checkout or reservation processing yet. All cart operations and data live in the browser.

1.2 High-Level Features
- Modern hero section with a full-width background image and clear call-to-action buttons.
- Category-based exploration of menu types (Fast Food, Main Course, BBQ, Desserts, Drinks, Salads, etc.).
- “Today’s Specials” highlight section with premium cards.
- “Why Choose Us” feature grid explaining restaurant strengths.
- Animated statistics (customers, dishes served, years of experience, rating).
- Auto-rotating testimonials slider with manual navigation.
- Visual gallery with lightbox (click to enlarge dish images).
- Dedicated Menu page with:
  - Category tabs (e.g. Starters, Main Course, Fast Food, BBQ, Salads, Desserts, Drinks).
  - Search bar to filter by dish name or description.
  - Reusable menu cards with Add to Cart.
- Global cart drawer:
  - Persistent cart state via localStorage.
  - Increase/decrease quantity, remove items, clear cart, total amount.
- Basic placeholder pages for About, Contact, and Reservation to be expanded later.

1.3 Target Users
- End customers exploring Foodies’ offerings (desktop or laptop users; mobile layout is partially addressed via responsive CSS).
- Restaurant staff, designers, or developers who want a clean base for a full restaurant app.

  - Colored gradient dot.

  - Home `/`

  - Reservation `/reservation`

- Cart button:
  - Uses `useCart()` to access `cartCount` and `toggleCart`.
  - Shows a badge with the total count of items in the cart.
  - On click, toggles the global cart drawer open/close.


====================================================
5. SHARED CART STATE AND DATA FLOW
====================================================

5.1 Cart Context (`CartContext.jsx`)
- Creates `CartContext` with React’s `createContext`.
- Storage key: `"foodies_cart_v1"` in `localStorage`.

5.2 State Variables
- `isOpen` (boolean):
  - Controls whether the cart drawer is visible.
  - Modified by `openCart`, `closeCart`, and `toggleCart`.
- `cart` (array of items):
  - Each item has at least: `id`, `name`, `price`, `category`, `desc`, `emoji`, and `qty`.
  - Initialized from `localStorage` on first render.
    - Tries to parse stored JSON. If parsing fails, defaults to an empty array.

5.3 Derived Values
- `cartCount` (`useMemo`):
  - Sum of `qty` across all cart items.
  - Used for the badge in the navbar cart button.
- `total` (`useMemo`):
  - Sum of `price * qty` across all items.
  - Displayed in the cart drawer footer.

5.4 Persistence
- `useEffect` writes the latest cart to `localStorage` whenever the `cart` state changes:
  - `localStorage.setItem(STORAGE_KEY, JSON.stringify(cart))`
  - Ensures cart is preserved across page refreshes.

5.5 Cart Operations
- `openCart()` – sets `isOpen` to `true`.
- `closeCart()` – sets `isOpen` to `false`.
- `toggleCart()` – toggles `isOpen`.
- `addToCart(product)`:
  - Checks if an item with the same `id` exists in the cart.
  - If found:
    - Increments its `qty` by 1.
  - If not found:
    - Adds a new item with `qty: 1`.
  - Finally opens the cart (`setIsOpen(true)`).
- `removeFromCart(id)`:
  - Filters out the item whose `id` matches.
- `incQty(id)`:
  - Maps over `cart` and for the matching id, increments `qty` by 1.
- `decQty(id)`:
  - Decrements `qty` by 1 for the matching id.
  - Removes any items whose `qty` drops to 0 or below.
- `clearCart()`:
  - Empties the entire cart array.

5.6 Hook Usage
- `useCart()`:
  - Custom hook that wraps `useContext(CartContext)`.
  - Throws an error if used outside of `<CartProvider>`, enforcing proper usage.

5.7 End-to-End Cart Flow
1. User visits `/menu`.
2. `Menu.jsx` renders `MenuCard` components for each item in `menuData`.
3. User clicks “Add” on a `MenuCard`.
4. `MenuCard` calls `addToCart(item)` from `useCart()`.
5. `CartContext` updates the `cart` state:
   - Either increments an existing item’s quantity or adds a new one.
   - Sets `isOpen` to `true`.
6. `cartCount` gets recomputed and the badge in `Navbar` updates.
7. `CartDrawer` becomes visible:
   - Shows a list of cart items.
   - Shows total amount and action buttons.
8. Inside the cart, user can:
   - Increase/decrease quantity.
   - Remove a single item.
   - Clear the entire cart.
9. Changes are instantly written to `localStorage` and reflected in UI.

6. PAGES
====================================================

6.1 Home Page (`Home.jsx`)
- Imports and composes the main homepage sections:
  - `Hero`
  - `Categories`
  - `Specials` (Today’s Specials)
  - `WhyChooseUs`
  - `Stats`
  - `Reviews`
  - `Gallery`
- The page acts as a layout container only; logic is inside each section component.

6.2 Menu Page (`Menu.jsx`)
- Purpose:
  - Central location for menu exploration and adding items to cart.

- Inputs:
  - Imports `MenuCard` for presentation.
  - Imports `menuData` from `data/menuData.js`.

- Derived Data:
  - `categories` (`useMemo`):
    - Builds a unique list of categories from `menuData`.
    - Prepends “All” to allow showing all items.
  - `active` (`useState`):
    - Currently selected category (default: “All”).
  - `query` (`useState`):
    - Search text for filtering.
  - `filtered` (`useMemo`):
    - Filters `menuData` according to:
      - Category: show all or only matching category.
      - Search: case-insensitive match on `name` or `desc`.

- Layout and Controls:
  - Header:
    - “Our Menu” title and short description.
  - Search bar:
    - Text input bound to `query`.
    - Clear button resets `query` to empty.
  - Category tabs:
    - Rendered as buttons from `categories`.
    - Active tab has a distinct background/border color.
  - Result count:
    - Shows “Showing X items” where X is `filtered.length`.
  - Cards grid:
    - Renders each `filtered` item as a `MenuCard`.

6.3 About, Contact, Reservation Pages
- `About.jsx`:
  - Returns a simple `<h1>` with “About Page” and basic padding.
- `Contact.jsx`:
  - Returns a simple `<h1>` with “Contact Page”.
- `Reservation.jsx`:
  - Returns a simple `<h1>` with “Reservation Page”.
- These are placeholders and are intended to be expanded with forms, contact details, and reservation logic in the future.

====================================================
12. EXTENDING THE PROJECT
====================================================

12.1 Adding New Menu Items
1. Open `client/src/data/menuData.js`.
2. Append a new object to the `menuData` array with:
   - Unique `id`.
   - `name`, `price`, `category`, `desc`, `emoji`.
3. The new item will automatically appear on the `Menu` page and can be filtered via category and search.

12.2 Wiring Specials to Cart
1. Import `useCart` into the Specials component.
2. Replace the UI-only “Add to Cart” button with a call to `addToCart` for the corresponding data structure (id, name, price, etc.).
3. Optionally share data between `menuData` and `Specials` to avoid duplication.

12.3 Enhancing About/Contact/Reservation Pages
- `About`:
  - Add restaurant story, chef profiles, timelines, and images.
- `Contact`:
  - Add contact form, phone number, address, map integration (Google Maps embed).
- `Reservation`:
  - Add form with date/time selection, guests count, and contact details.
  - Connect to a backend API when ready.

12.4 Connecting Real Checkout
- Replace the “Checkout (UI only)” button’s placeholder behavior in `CartDrawer` with:
  - API call to a backend that processes the order.
  - Or redirect to a payment page, depending on the architecture.
- Because cart data is centrally stored in `CartContext`, integrating with a backend is straightforward: you can send the `cart` and `total` to a server endpoint.

13. SUMMARY
====================================================

This restaurant website is a well-structured React SPA focusing on a premium dark UI, clear navigation, and an interactive menu + cart experience. The codebase separates concerns into pages, shared components, homepage sections, context for global state, and a data module for menu information. Styling uses a combination of global CSS (with themes and utilities) and inline styles to deliver a modern, animated, and responsive interface. The frontend is ready to be extended with richer pages (About, Contact, Reservation) and a real backend for reservations and checkout.

import { createContext, useContext, useEffect, useMemo, useState } from "react";

const CartContext = createContext(null);

const STORAGE_KEY = "foodies_cart_v1";

export function CartProvider({ children }) {
  const [isOpen, setIsOpen] = useState(false);

  const [cart, setCart] = useState(() => {
    try {
      const saved = localStorage.getItem(STORAGE_KEY);
      return saved ? JSON.parse(saved) : [];
    } catch {
      return [];
    }
  });

  useEffect(() => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(cart));
  }, [cart]);

  const cartCount = useMemo(
    () => cart.reduce((sum, item) => sum + item.qty, 0),
    [cart]
  );

  const total = useMemo(
    () => cart.reduce((sum, item) => sum + item.price * item.qty, 0),
    [cart]
  );

  function openCart() {
    setIsOpen(true);
  }
  function closeCart() {
    setIsOpen(false);
  }
  function toggleCart() {
    setIsOpen((v) => !v);
  }

  function addToCart(product) {
    setCart((prev) => {
      const found = prev.find((x) => x.id === product.id);
      if (found) {
        return prev.map((x) =>
          x.id === product.id ? { ...x, qty: x.qty + 1 } : x
        );
      }
      return [...prev, { ...product, qty: 1 }];
    });
    setIsOpen(true);
  }

  function removeFromCart(id) {
    setCart((prev) => prev.filter((x) => x.id !== id));
  }

  function incQty(id) {
    setCart((prev) =>
      prev.map((x) => (x.id === id ? { ...x, qty: x.qty + 1 } : x))
    );
  }

  function decQty(id) {
    setCart((prev) =>
      prev
        .map((x) => (x.id === id ? { ...x, qty: x.qty - 1 } : x))
        .filter((x) => x.qty > 0)
    );
  }

  function clearCart() {
    setCart([]);
  }

  const value = {
    cart,
    cartCount,
    total,
    isOpen,
    openCart,
    closeCart,
    toggleCart,
    addToCart,
    removeFromCart,
    incQty,
    decQty,
    clearCart,
  };

  return <CartContext.Provider value={value}>{children}</CartContext.Provider>;
}

export function useCart() {
  const ctx = useContext(CartContext);
  if (!ctx) throw new Error("useCart must be used inside CartProvider");
  return ctx;
}

import { useMemo, useState } from "react";
import MenuCard from "../components/MenuCard";
import { menuData } from "../data/menuData";

export default function Menu() {
  const categories = useMemo(() => {
    return ["All", ...new Set(menuData.map((i) => i.category))];
  }, []);

  const [active, setActive] = useState("All");
  const [query, setQuery] = useState("");

  const filtered = useMemo(() => {
    const q = query.trim().toLowerCase();

    return menuData.filter((item) => {
      const matchCategory = active === "All" || item.category === active;
      const matchSearch =
        q === "" ||
        item.name.toLowerCase().includes(q) ||
        item.desc.toLowerCase().includes(q);

      return matchCategory && matchSearch;
    });
  }, [active, query]);

  return (
    <div style={{ padding: "40px 0" }}>
      <div className="container">
        <h1 style={{ marginBottom: 8 }}>Our Menu</h1>
        <p style={{ color: "rgba(255,255,255,0.72)", marginTop: 0 }}>
          Choose your favorite dish from our categories.
        </p>

        {/* Search Bar */}
        <div style={styles.searchRow}>
          <input
            style={styles.searchInput}
            type="text"
            placeholder="Search dishes... (e.g. biryani, pizza)"
            value={query}
            onChange={(e) => setQuery(e.target.value)}
          />
          <button style={styles.clearBtn} onClick={() => setQuery("")}>
            Clear
          </button>
        </div>

        {/* Category Buttons */}
        <div style={styles.tabs}>
          {categories.map((c) => (
            <button
              key={c}
              onClick={() => setActive(c)}
              style={{
                ...styles.tab,
                ...(active === c ? styles.tabActive : {}),
              }}
            >
              {c}
            </button>
          ))}
        </div>

        {/* Result Count */}
        <div style={styles.count}>
          Showing <b>{filtered.length}</b> items
        </div>

        {/* Cards Grid */}
        <div style={styles.grid}>
          {filtered.map((item) => (
            <MenuCard key={item.id} item={item} />
          ))}

export default function Stats() {
  const stats = useMemo(
    () => [
      { id: 1, label: "Happy Customers", value: 10000, suffix: "+" },
      { id: 2, label: "Dishes Served", value: 500, suffix: "+" },
      { id: 3, label: "Years Experience", value: 5, suffix: "+" },
      { id: 4, label: "Average Rating", value: 4.8, suffix: "⭐" },
    ],
    []
  );

  return (
    <section className="section" style={{ paddingTop: 0 }}>
      <div className="container">
        <div className="card fadeUp" style={styles.wrap}>
          {stats.map((s) => (
            <StatCard key={s.id} label={s.label} value={s.value} suffix={s.suffix} />
          ))}
        </div>
      </div>
    </section>
  );
}

function StatCard({ label, value, suffix }) {
  const [display, setDisplay] = useState(0);

  useEffect(() => {
    // animate count up in ~900ms
    const duration = 900;
    const start = performance.now();

    function tick(now) {
      const progress = Math.min((now - start) / duration, 1);

      // smooth easing
      const eased = 1 - Math.pow(1 - progress, 3);

      const current = value * eased;

      // handle decimals (for rating)
      const formatted =
        Number.isInteger(value) ? Math.round(current) : Math.round(current * 10) / 10;

      setDisplay(formatted);

      if (progress < 1) requestAnimationFrame(tick);
    }

    const raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [value]);

  return (
    <div style={styles.item}>
      <div style={styles.value}>
        {display}
        <span style={styles.suffix}>{suffix}</span>
      </div>
      <div style={styles.label}>{label}</div>
    </div>
  );
}

const styles = {
  wrap: {
    padding: 18,
    borderRadius: 18,
    display: "grid",
    gridTemplateColumns: "repeat(auto-fit, minmax(200px, 1fr))",
    gap: 12,
    background:
      "linear-gradient(180deg, rgba(255,255,255,0.08), rgba(255,255,255,0.03))",
    border: "1px solid rgba(255,255,255,0.12)",
  },
  item: {
